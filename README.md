# Sefox
dripmarket/index.html
**DripMarket** is rebuilt as a single 59KB file — zero dependencies, opens directly in any browser.

**File:** `dripmarket/index.html` (644 lines)

**All 8 screens:**

| Screen | Features |
|--------|----------|
| **Home** | Logo, search, 6 categories with icons, hero banner, Daily Deals countdown timer, Trending grid, Featured scroll, Under 50k UGX grid |
| **Product** | Animated floating image, price with discount badge, size/color selectors with active states, description, 3 reviews, Add to Cart + Buy Now + Wishlist bottom bar |
| **Search** | Real-time search, category filter chips, sort (newest/cheapest/popular), price range + size filter modal, product count |
| **Cart** | Quantity +/- controls, remove button, color/size display, subtotal + UGX 5,000 delivery + total, Clear All, Proceed to Checkout |
| **Checkout** | Name, phone, delivery address, Mobile Money / Cash on Delivery payment toggle, order summary, Confirm Order |
| **Orders** | 5 tabs (All/Pending/Confirmed/Out for Delivery/Delivered), order cards with status badges, item details, totals |
| **Account** | Profile header with avatar, Wishlist, Orders, Saved Addresses (editable modal), Settings, Admin Dashboard link, Log Out |
| **Admin** | 4 stat cards (Sales/Orders/Pending/Products), Products tab with add/edit/delete + image upload placeholder, Orders tab with status dropdown, Sales tab with revenue breakdown |

**Design:** Purple gradient theme, Plus Jakarta Sans font, glassmorphic header/nav, smooth animations, SVG icons, responsive mobile-first layout, UGX pricing throughout.
